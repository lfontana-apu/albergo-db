# Albergo DB

Esercizio 4x03 - Database Albergo (parte 1)

Database realizzato con MySQL/phpMyAdmin.

Il database contiene le tabelle:
- `cliente`
- `camera`
- `tipologia_camera`
- `prenotazione`
- `staff`
- `ruolo_staff`
- `servizio_extra`
- `prenotazione_servizio`
- `recensione`
