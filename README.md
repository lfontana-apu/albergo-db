# Albergo DB

Esercizi 4x03 e 4x04 - Database Albergo

Database realizzato con MySQL/phpMyAdmin.

Il database contiene le tabelle:
- `cliente`
- `camera`
- `tipologia_camera`
- `prenotazione`
- `staff`
- `ruolo_staff`
- `servizio_extra`
- `prenotazione_servizio`
- `recensione`
